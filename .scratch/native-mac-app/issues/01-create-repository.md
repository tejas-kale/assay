# Create the new app's repository and Mac build setup

Type: task
Status: open

## Question

HITL. Before any prototype can run, the user does the following on their Mac:
- Create the open-source GitHub repository for the new app and choose its name and licence.
- Install the current Xcode.
- Check that a Developer ID Application certificate is in the keychain.
- Make the repository reachable from Claude sessions (attach it here, or run Claude Code locally on the Mac).

Record the repository URL, Xcode version, signing identity name (not secrets) and the chosen licence.
